# Public-safe demo script

1. Open a synthetic case and show the observation fields.
2. Submit a response that contains a clear observation and one missing piece of evidence.
3. Show structured feedback linked to rubric criteria.
4. Trigger a review state for missing evidence or overconfident language.
5. Show the teacher decision and remediation assignment.
6. End on the public data boundary and explain why real course materials are not included.

The demo is educational and synthetic. Do not add real student information, clinical instructions, textbook excerpts, or private platform details.
